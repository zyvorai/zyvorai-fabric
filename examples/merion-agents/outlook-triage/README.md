# outlook-triage

Lists your unread Outlook inbox mail (sender, subject, date) with the read-only `outlook-read` credential, in one Graph request. No model. What it prints is text from other people and it does nothing with it.

Needs a Microsoft connection: see [Microsoft 365](../../../docs/merion/connectors/README.md#microsoft-365-outlook-mail-and-calendar). Not connected yet? The reply says "connect your microsoft account first". Not run against real Microsoft.
