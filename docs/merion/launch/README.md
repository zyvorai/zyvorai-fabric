# Launch drafts

Drafts for people to review, edit and post under their own name. **Nothing here is posted by tooling.** Every claim is one the repository
can back with a command; where it cannot, the draft says so. Read [TODO.md](../TODO.md) first: some claims (a signed Solvor build, a hardware
attested run) are not true yet and must not be made until they are.

| Draft | For |
|---|---|
| [technical-post.md](technical-post.md) | A blog post: what a sealed cell proves and how to check it yourself |
| [show-hn.md](show-hn.md) | A short "Show HN" style post and answers to the questions it will get |
| [solvor-demo-script.md](solvor-demo-script.md) | A 60-second screen recording of Solvor, shot by shot |

Rules for every post: say `software-test` out loud, never say "confidential" or "attested" until a verified hardware run exists, link the
repository, and give the reader a command that reproduces the number you quote.
